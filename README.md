# Homebax Browser (HB Browser)

**HB Browser** is a modern web browser developed by **Homebax Studios**.
- **HB Browser** – A modern desktop web browser.

## Programming Languages & Build System

- **C++** – Main application programming language.
- **CMake** – Build system.
- **HTML** – Web interface structure.
- **CSS** – Web interface styling.
- **JavaScript** – Web interface functionality.

## Web Rendering

- **Microsoft Edge WebView2** – Web rendering technology.
